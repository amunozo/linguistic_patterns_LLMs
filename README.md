Research code and generated article data for **[Contrasting Linguistic Patterns
in Human and LLM-Generated News
Text](https://doi.org/10.1007/s10462-024-10903-2)**, by Alberto
Muñoz-Ortiz, Carlos Gómez-Rodríguez, and David Vilares, published in
*Artificial Intelligence Review* 57, 265 (2024).

The study compares human-written New York Times lead paragraphs with text
generated by six base language models. It measures morphological, syntactic,
psychometric, and sociolinguistic patterns. This repository is a research
artifact rather than a maintained production library; the scripts expose the
paper's pipeline while keeping data, model, and hardware choices explicit.

## Repository contents

- `data/`: generated lead paragraphs for Falcon 7B, Mistral 7B, and LLaMA
  7B/13B/30B/65B.
- `scripts/download_articles.py`: download monthly NYT Archive API responses.
- `scripts/prepare_articles.py`: filter and deduplicate the article records used
  for generation.
- `scripts/generate.py`: generate lead paragraphs from the headline and first
  three human-written words.
- `scripts/parse_classify.py`: add Stanza parses, constituency trees, and
  emotion labels.
- `src/`: analysis utilities used by the notebook.
- `notebooks/analysis.ipynb`: exploratory analysis and paper figures.
- `tests/`: fast checks for preprocessing, result alignment, and analysis
  helpers. Tests do not download models or data.

## Installation

Python 3.10 or newer is recommended.

```bash
git clone https://github.com/amunozo/linguistic_patterns_LLMs.git
cd linguistic_patterns_LLMs
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Parsing also requires the English Stanza resources:

```bash
python -m stanza.download en
```

GPU execution is optional for parsing and classification but is normally
required for generation with the larger models. Pass `--load-in-8bit` to the
generation script only after installing a compatible `bitsandbytes` build.

## Data pipeline

The paper used NYT articles published from 1 October 2023 through 24 January
2024. The NYT API key is read from the environment. It is never accepted as a
command-line value, so it is less likely to be stored in shell history.

```bash
cp .env.example .env
# Edit .env, then:
python scripts/download_articles.py 2023-10 2024-01 artifacts/nyt-archive
python scripts/prepare_articles.py \
  artifacts/nyt-archive artifacts/original.json \
  --start 2023-10-01 --end 2024-01-24
```

The Archive API can be corrected after publication, so a fresh download is not
guaranteed to be byte-identical to the original snapshot. Empty lead paragraphs
are excluded, and duplicate `_id` or `web_url` records are removed.

Generate one output file per model. Model IDs are explicit because the original
LLaMA checkpoints may be available as local converted weights rather than
public Hugging Face IDs.

```bash
python scripts/generate.py \
  --input artifacts/original.json \
  --output-dir artifacts/generated \
  --model mistral_7B=mistralai/Mistral-7B-v0.1 \
  --model falcon_7B=tiiuae/falcon-7b \
  --device auto --seed 0
```

For a quick pipeline check, add `--limit 10`. Generation keeps the original
article metadata and replaces `lead_paragraph` in each output copy. The source
file is not modified.

Add linguistic and emotion annotations as follows:

```bash
python scripts/parse_classify.py \
  --input artifacts/generated/mistral_7B.json \
  --output artifacts/annotated/mistral_7B.json \
  --device auto --batch-size 32
```

Use `--skip-emotion` or `--skip-parsing` when only one annotation stage is
needed. Every command supports `--help` and accepts explicit input and output
paths.

## Analysis

The notebook records the exploratory analysis used for the paper. Start Jupyter
from the repository root so that `src` is importable:

```bash
python -m pip install jupyter plotly
jupyter notebook notebooks/analysis.ipynb
```

Some notebook cells use the Linear Arrangement Library (`lal`), which must be
installed separately for those analyses. The notebook reflects the original
interactive workflow and is not used as an automated test.

## Development checks

```bash
python -m pip install -r requirements-dev.txt numpy pandas nltk
python -m ruff check .
python -m pytest
```

The automated checks cover deterministic preprocessing and analysis helpers.
They do not claim end-to-end reproduction of GPU experiments, which additionally
requires the original model weights, Stanza resources, NYT snapshot, and
substantial compute.
